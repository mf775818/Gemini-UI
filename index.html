Gemini Ultimate Userscript

This project is a Tampermonkey userscript, not a standard web application. The dev server is now running to serve the script file for easy installation.

To use this script:

  1. Install a userscript manager like Tampermonkey in your browser.
  2. Click the button below to install or update the script.
  3. Open Gemini to see the enhancements!
